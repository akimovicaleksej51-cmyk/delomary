# Подключение бронирования и заявок Loony Room к Telegram

В этом архиве файлы для вашего репозитория `delomary`:

- `index.html` — обновлён: без номера дела, с компактной галереей и
  навигацией по фото, форма брони реально отправляет данные, поле email в
  Loony Room тоже реально отправляет данные (в отдельный чат — см. ниже),
  убран чёрный прямоугольник в тексте Loony Room.
- `api/book.js` — серверная функция для формы брони квеста, шлёт заявку в
  Telegram-бот квеста.
- `api/lead.js` — отдельная серверная функция для email из Loony Room, шлёт
  в **другой** Telegram-бот/чат (специально не смешиваем брони квеста и
  заявки на комнату).
- `package.json` — нужен, чтобы Vercel правильно запускал функции из `api/`
  (если у вас уже есть свой `package.json` в репозитории — просто добавьте
  в него строку `"type": "module"`, остальное не обязательно).

`assets/` и `README.md` не трогайте — они не менялись.

## Бот для брони квеста (если ещё не настроен)

1. Бот через @BotFather → `TELEGRAM_BOT_TOKEN`.
2. chat_id → `TELEGRAM_CHAT_ID` (см. способ ниже).

## Бот для заявок Loony Room (новый, отдельный)

Вы создаёте второго бота специально для этого — переменные для него
называются **по-другому**, не перепутайте:

1. **Создать бота** через @BotFather (`/newbot`) → получите токен, это
   будет `LOONY_BOT_TOKEN`.
2. **Узнать chat_id**:
   - Если это личный чат с ботом — напишите ему `/start`, затем откройте
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
     `"chat":{"id":ЧИСЛО,...}`.
   - Если добавили бота в группу — отправьте в группу `/start` (важно
     именно со слэшем), затем так же откройте `getUpdates`. Для группы
     число будет **отрицательным** (например `-1004396498637`).
   - Если `getUpdates` возвращает пусто — отключите приватность бота:
     @BotFather → `/mybots` → ваш бот → **Bot Settings** → **Group
     Privacy** → **Turn off**, и повторите попытку.
   Это значение — `LOONY_CHAT_ID`.

## Что сделать с файлами

1. **Залить файлы** из этого архива в репозиторий `delomary` на GitHub
   (Add file → Upload files, с подтверждением перезаписи `index.html`;
   `api/lead.js` — новый файл, конфликтов не будет).
2. **Прописать переменные** в Vercel → Project → Settings → Environment
   Variables (все четыре, если настраиваете с нуля):
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `LOONY_BOT_TOKEN`
   - `LOONY_CHAT_ID`
3. Сделать **Redeploy** (Vercel → Deployments → ⋯ → Redeploy), чтобы
   функции подхватили новые переменные.

## Проверка

- Форма брони: заполните имя и телефон, нажмите «Отправить заявку на
  бронь» — в Telegram-боте квеста должно появиться сообщение с деталями.
- Loony Room: впишите email, нажмите «Сообщить мне первому» — в
  Telegram-боте Loony Room должно появиться сообщение с этим адресом.
- Ошибка «форма временно не работает» / «попробуйте ещё раз чуть позже» —
  значит для соответствующей формы не заданы (или заданы с опечаткой)
  переменные окружения.
