# Подключение бронирования к Telegram

В этом архиве три новых/изменённых файла для вашего репозитория `delomary`:

- `index.html` — форма брони теперь реально отправляет данные (не показывает
  фиктивное сообщение, как раньше), плюс все правки, что уже были: без
  номера дела, с компактной галереей и рабочим полем email в Loony Room.
- `api/book.js` — серверная функция Vercel, которая получает заявку и шлёт
  её вам в Telegram.
- `package.json` — нужен, чтобы Vercel правильно запускал `api/book.js`
  (если у вас уже есть свой `package.json` в репозитории — просто добавьте
  в него строку `"type": "module"`, остальное не обязательно).

`assets/` и `README.md` не трогайте — они не менялись.

## Что нужно от вас

1. **Создать бота** через @BotFather в Telegram (`/newbot`) — получите
   `TELEGRAM_BOT_TOKEN`.
2. **Узнать chat_id**: напишите новому боту любое сообщение (например
   `/start`), затем откройте в браузере
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` — в ответе найдите
   `"chat":{"id":ЧИСЛО,...}`. Это и есть `TELEGRAM_CHAT_ID`.
3. **Залить файлы** из этого архива в репозиторий `delomary` на GitHub
   (Add file → Upload files, с подтверждением перезаписи `index.html`).
4. **Прописать переменные** в Vercel → Project → Settings → Environment
   Variables:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
5. Сделать **Redeploy** (Vercel → Deployments → ⋯ → Redeploy), чтобы
   функция подхватила новые переменные.

## Проверка

Откройте сайт, заполните форму брони (имя и телефон обязательны) и
нажмите «Отправить заявку на бронь». Если всё настроено правильно — в
Telegram придёт сообщение с именем, телефоном, количеством игроков, датой,
временем и ценой. Если появится ошибка «форма временно не работает» —
значит переменные окружения не заданы или в них опечатка.

## Что дальше

Поле email в блоке Loony Room пока только показывает подтверждение на
экране — само письмо никуда не уходит. Как только решите, что с ним
делать (слать в тот же чат или в отдельный), это отдельная небольшая
доработка `api/`.
