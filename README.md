# Дело Мэри. Скажи им, что я здесь — сайт квеста

Одностраничный сайт квеста «Дело Мэри. Скажи им, что я здесь» (Loony Games, Минск).
Чёрно-охровая цветовая гамма, стилизация под архивное «дело» психиатрической клиники,
интерактивная сетка бронирования с пересчётом цены и карта проезда.

## Структура проекта

```
.
├── index.html   ← весь сайт: разметка, стили и скрипты в одном файле
└── README.md    ← этот файл
```

Сайт полностью статический: никакого бэкенда, сборки или зависимостей не требует.
Достаточно открыть `index.html` в браузере — он уже рабочий.

## Что уже сделано на сайте

- Карточка квеста: длительность, число игроков, сложность, возрастной ценз, цена
- Описание, теги, фотогалерея с лайтбоксом
- Рейтинг и достижения с анимацией при прокрутке
- Интерактивная сетка бронирования: выбор числа игроков (1–6), даты, времени сеанса —
  цена пересчитывается автоматически (тарифы по числу игроков + доплата за поздний сеанс 23:00)
- Отзывы игроков
- FAQ-аккордеон
- Блок-тизер «Loony Room» (комната отдыха в аренду) — заглушка «скоро»
- Карта проезда (Яндекс.Карты, встроенный виджет)
- Контакты и УНП организатора в подвале

## ⚠️ Важно перед публичным запуском

Форма бронирования и подписка на Loony Room сейчас **не отправляют данные никуда** —
это готовый интерфейс без бэкенда. Прежде чем давать ссылку реальным клиентам, нужно
подключить приём заявок одним из способов:

- [Formspree](https://formspree.io) или [Getform](https://getform.io) — вставить `action`
  формы на их endpoint, заявки будут приходить на почту (бесплатный тариф есть)
- Telegram-бот — заявка уходит прямо в чат администратора
- Реальный виджет бронирования Extrareality — встроить их iframe/скрипт вместо своего макета

Также стоит проверить у организатора актуальность цен и расписания сеансов — на сайте
указаны значения на момент сборки страницы.

## Как опубликовать: GitHub → Vercel

### Шаг 1. Создать репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и войдите (или зарегистрируйтесь — бесплатно).
2. Нажмите **New repository** (зелёная кнопка справа вверху или на github.com/new).
3. Укажите имя, например `delo-meri-site`. Оставьте репозиторий **Public**.
4. Не добавляйте README/gitignore при создании (он уже есть у нас) — просто нажмите **Create repository**.

### Шаг 2. Загрузить файлы в репозиторий

Самый простой способ — без установки git, через браузер:

1. На странице пустого репозитория нажмите **uploading an existing file**
   (или **Add file → Upload files**).
2. Перетащите туда `index.html` и `README.md` из этой папки.
3. Внизу нажмите **Commit changes**.

Если пользуетесь git в терминале:

```bash
cd путь/к/папке/site
git init
git add .
git commit -m "Первая версия сайта квеста"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/delo-meri-site.git
git push -u origin main
```

### Шаг 3. Подключить репозиторий к Vercel

1. Зайдите на [vercel.com](https://vercel.com) и нажмите **Sign Up**.
2. Выберите вход **Continue with GitHub** — так Vercel сразу увидит ваши репозитории.
3. На дашборде нажмите **Add New → Project**.
4. Найдите в списке `delo-meri-site` и нажмите **Import**.
5. Vercel сам определит, что это статический сайт (Framework Preset: **Other**) —
   никаких настроек сборки менять не нужно, поле Build Command можно оставить пустым.
6. Нажмите **Deploy**.

Через 20–30 секунд Vercel выдаст рабочую ссылку вида:

```
https://delo-meri-site.vercel.app
```

Её уже можно отправлять кому угодно.

### Шаг 4. Обновления сайта в будущем

Любое новое изменение — правите `index.html` локально или прямо на GitHub
(кнопка карандаша на странице файла) → делаете commit → Vercel автоматически
пересобирает и обновляет сайт по той же ссылке за секунды. Ничего вручную
на Vercel нажимать не нужно.

### Шаг 5 (по желанию). Свой домен вместо `.vercel.app`

1. В проекте на Vercel откройте вкладку **Settings → Domains**.
2. Введите свой домен (например, `delo-meri.by`, купленный на hoster.by/reg.by).
3. Vercel покажет DNS-записи (обычно A-запись или CNAME) — добавьте их у
   регистратора домена в панели управления DNS.
4. Подождите обновления DNS (обычно от пары минут до пары часов) — домен
   заработает поверх того же сайта, с бесплатным HTTPS-сертификатом.
